# Frontend asset provenance

This file records the origin and intended use of visual assets shipped with Vector52.

## Original generated illustrations

The following assets were generated on 8 September 2026 with OpenAI Codex ImageGen under Omar's direction,
then resized and converted to WebP for the PWA. They are original Vector52 assets; neither image is copied from
ethereum.org or ETHGlobal and neither contains an official ecosystem logo.

### `public/images/vector52-hero.webp`

- **Use:** landing-page hero.
- **Prompt summary:** an open digital evidence observatory with an analyst, transparent evidence cards,
  transaction blocks and a central faceted crystal; fine indigo linework, isometric editorial composition,
  Ethereum-adjacent lavender/cyan/mint/peach palette; no text, official logos or copied scenes.
- **SHA-256:** `B07430B5F66F30D9403B356F07C51D498BD96877E14A1891DFF82FA9B4CE9D92`

### `public/images/evidence-layers.webp`

- **Use:** explanation of the evidence hierarchy.
- **Prompt summary:** four floating layers for transaction data, indexed graph, exchange flow and audit verdict,
  connected to a crystal vault; original editorial geometry with a light Ethereum-ecosystem palette; no text,
  official logos or copied scenes.
- **SHA-256:** `810AB5E916324ED8585DF5BD4B6B03D284F682B0114A9B6D239CC5E844EDA2B8`

## Design references

- [ethereum.org](https://ethereum.org/) — editorial illustration, educational hierarchy and light surfaces.
- [ETHGlobal](https://ethglobal.com/) — asymmetric hero composition, strong sans-serif hierarchy and ecosystem cards.
- [UI/UX Pro Max demo](https://uupm.cc/demo/educational-platform) — scannable card rhythm.
- [Devconnect app](https://app.devconnect.org/) — bright event palette and explicit PWA installation affordance.

Vector52 does not reuse the reference sites' illustrations, logos, layout code or proprietary typefaces.
